# java_learning

Подготовка к стажировке Java/Kotlin backend (весна 2027).

## Структура

- `core/` — Java Core: синтаксис, ООП, коллекции, исключения, многопоточность
- `algorithms/` — решения задач (LeetCode и др.), по темам
- `sql/` — запросы и схемы PostgreSQL

## План

1. 5 окт – 1 ноя: Java Core + старт алгоритмов
2. 2 ноя – 6 дек: Java глубже + SQL/PostgreSQL
3. 7 дек – 17 янв: Spring Boot + пет-проект (отдельный репозиторий)
4. 18 янв – 14 фев: Docker, Kotlin, сети и ОС, резюме
5. С 15 фев: отбор на стажировки
